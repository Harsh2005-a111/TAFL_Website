REGEX → AUTOMATA CONVERTER
Quick-start guide · Thompson's Construction Engine
Getting Started
1
Type a regular expression into the input field on the left panel — e.g. (a|b)*abb — or pick one of the quick-example chips below it.
2
Click Convert or press Enter. The tool instantly builds an ε-NFA via Thompson's Construction and then computes the equivalent DFA via subset construction.
3
Switch between views using the tabs at the top: ε-NFA for the non-deterministic automaton, DFA for the deterministic one, and Table for the full transition table.
Navigating the Canvas
4
Drag nodes to rearrange the diagram — select the ◈ Select tool (default), then click and drag any state circle to a new position. Edges update live.
5
Pan the canvas by switching to the ✥ Pan tool and dragging, or simply drag on empty canvas space in Select mode.
6
Zoom with the + / − buttons or the mouse scroll wheel. Use ⊡ to fit the whole automaton back into view.
Simulating & Exporting
7
Enter any string in the Simulate Input box and click Run (or press Enter) to check whether the NFA accepts or rejects it. The trace path is shown below the result.
8
Export the automaton as DOT notation (Graphviz-compatible) via the toolbar, or use SVG for a screenshot-ready export.
Supported Regex Syntax
a·b — Concatenation (implicit)
a | b — Union / alternation
a* — Kleene star (zero or more)
a+ — One or more occurrences
a? — Zero or one (optional)
( … ) — Grouping / precedence
